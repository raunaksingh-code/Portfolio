Financial Modeling

Hindustan Unilever — 5-Year Financial Blueprint

A five-year forward financial model benchmarking HUL against FMCG peers to support a data-backed investment recommendation — the exercise whose methodology was later extended into the Britannia due-diligence report.

TypeAcademic Financial Modeling
InstitutionGreat Lakes Institute of Management, Gurgaon
Horizon5-Year Projection
Scope20+ KPIs Benchmarked
Objective

Assess Hindustan Unilever's financial health and strategic positioning over a five-year horizon and translate the analysis into a structured, data-backed investment recommendation report — as an academic financial modeling exercise at Great Lakes Institute of Management.

Methodology & Process

The blueprint followed the standard equity-research financial modeling sequence: build the historical base, project forward, benchmark against peers, then translate the model into a recommendation.

01

Historical Financial Base

Compiled HUL's historical financial statements as the base year for the model, establishing the starting point for every forward projection.

02

Five-Year Projection

Built a full five-year projected financial statement set — not a single-year snapshot — covering revenue, margins and working capital drivers.

03

KPI & Ratio Modeling

Modeled 20+ specific financial and operating KPIs, including margin, working-capital efficiency and return-ratio metrics, on top of the projected statements.

04

FMCG Peer Benchmarking

Benchmarked the modeled KPIs against large-cap FMCG peers to contextualize HUL's performance rather than assessing it in isolation.

05

Recommendation Synthesis

Synthesized the projection and benchmarking work into a structured, evidence-based investment recommendation report.

Assumptions & Scope
  • This was an academic exercise conducted independently of any brokerage or institutional data feed, using HUL's own published financial statements as the sole primary source.
  • A five-year projection necessarily rests on continuity assumptions (stable category growth, no major structural shocks) rather than modeling discrete scenario branches, unlike the later bull/bear framing used in the Britannia report.
  • This report exists only as a CV bullet point and the underlying model file — unlike the Britannia and Quick Clean projects, no standalone written report survives to quote specific projected figures from, so findings here are described at the process level rather than with line-item numbers.
Key Findings
  • Produced a complete five-year projected financial statement set for HUL, rather than a single-year snapshot — the same structural approach later reused for the Britannia due-diligence exercise.
  • Benchmarked 20+ KPIs — margins, working-capital efficiency, return ratios — against large-cap FMCG peers to contextualize HUL's performance.
  • Delivered a structured, evidence-based investment recommendation report as the final output, rather than a set of disconnected spreadsheets.
Key Takeaways
  • Financial modeling is most useful when projection is paired with peer benchmarking — a standalone five-year model without an FMCG comparison set would say much less about HUL's relative positioning.
  • This exercise established the modeling discipline — historical base, forward projection, peer benchmarking, recommendation — that was carried forward directly into the more detailed Britannia equity due-diligence report.
